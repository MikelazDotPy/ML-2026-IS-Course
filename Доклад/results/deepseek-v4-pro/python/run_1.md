Вот пример функции на Python, которая решает поставленную задачу:

```python
import re
from collections import Counter

def word_count(text: str) -> dict:
    """
    Возвращает словарь, где ключи — слова из строки,
    а значения — количество их вхождений (регистр не учитывается,
    знаки препинания игнорируются).
    """
    # Приводим строку к нижнему регистру
    lowered = text.lower()
    # Извлекаем все слова: последовательности букв и цифр (\w+)
    words = re.findall(r'\w+', lowered)
    # Подсчитываем частоту каждого слова
    return dict(Counter(words))
```

**Краткое объяснение:**

1. `text.lower()` — переводим строку в нижний регистр, чтобы слова «Привет» и «привет» считались одинаковыми.
2. `re.findall(r'\w+', lowered)` — находим все непрерывные последовательности буквенно-цифровых символов (буквы, цифры, знак подчёркивания). Знаки препинания, пробелы и другие разделители автоматически игнорируются.
3. `Counter(words)` — удобный контейнер из стандартной библиотеки, который создаёт словарь с количеством повторений каждого элемента.
4. Преобразуем результат в обычный словарь с помощью `dict(...)`.
