### 1. Определение математического ожидания

**Дискретная случайная величина $X$**  
Пусть $X$ — дискретная случайная величина, принимающая значения $x_i$ с вероятностями $p_i = P(X=x_i)$. Математическим ожиданием (или средним значением) $E[X]$ называется сумма произведений всех возможных значений на их вероятности:

$$
E[X] = \sum_{i} x_i p_i
$$

**Непрерывная случайная величина $X$**  
Пусть $X$ — непрерывная случайная величина с плотностью распределения $f(x)$. Тогда её математическое ожидание определяется интегралом:

$$
E[X] = \int_{-\infty}^{\infty} x f(x)\,dx
$$

---

### 2. Основные свойства математического ожидания

Приведем основные свойства и краткие доказательства.

#### (а) Ожидание константы ($c$)
$$
E[c] = c
$$

**Доказательство:** 
Поскольку $P(c=c)=1$, то по определению для дискретной величины: $E[c]=c\cdot 1=c$. Для непрерывной: $\int_{-\infty}^\infty c f(x) dx = c\int_{-\infty}^\infty f(x) dx = c$.

#### (b) Линейность (аддитивность и однородность):
- **Аддитивность**: $E[X+Y] = E[X] + E[Y]$
- **Однородность**: $E[a X] = a\,E[X]$

**Доказательство (линейность):**
Для дискретных величин:
$$
E[X+Y] = \sum_{i,j}(x_i+y_j)p_{ij} = \sum_i x_i p_i + \sum_j y_j q_j = E[X]+E[Y]
$$
Аналогично для произведения и констант.

#### (в) Ожидание произведения независимых величин:
Если $X$ и $Y$ независимы, то:
$$
E[X Y] = E[X] \, E[Y]
$$

**Доказательство:**  
Дискретно: $E[X Y] = \sum_{i,j}x_iy_j p_{ij} = (\sum_i x_i p_i)(\sum_j y_j q_j) = E[X]E[Y]$.

#### (г) Неравенство Маркова (для неотрицательных величин):
Если $X \ge 0$, то $E[X] \ge 0$.

**Доказательство:** $E[X]=\sum x_i p_i \ge 0$ по неотрицательности $x_i$ и $p_i$.

#### (д) Свойство монотонности:
Если $X \le Y$ почти всюду, то $E[X] \le E[Y]$.

### 3. Примеры вычисления математических ожиданий

#### Пример 1: Дискретная величина
Случайная величина $X$ принимает значения $1, 2, 3$ с вероятностями $0.2, 0.5, 0.3$ соответственно. Найти $E[X]$:

$$
E[X] = 1 \cdot 0.2 + 2 \cdot 0.5 + 3 \cdot 0.3 = 0.2 + 1.0 + 0.9 = 2.1
$$

#### Пример 2: Непрерывная величина
Плотность равномерного распределения на отрезке $[0,4]$: $f(x)=\frac{1}{4}, 0 \leq x \leq 4$. Найти $E[X]$:

$$
E[X] = \int_0^4 x \cdot \frac{1}{4}\,dx = \left[\frac{x^2}{8}\right]_0^4 = \frac{16}{8}=2
$$
