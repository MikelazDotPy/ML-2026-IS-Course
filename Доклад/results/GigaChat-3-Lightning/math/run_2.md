## Определение математического ожидания

Математическое ожидание (обозначается $E[X]$ или $\mathbb{E}[X]$) — это числовая характеристика случайной величины, представляющая собой «среднее» значение при многократном повторении эксперимента.

### 1. Дискретный случай: случайная величина с дискретным распределением

Пусть $X$ — дискретная случайная величина, принимающая значения $x_1, x_2, \dots$ с соответствующими вероятностями $p_i = P(X=x_i)$, причём $\sum_{i=1}^{\infty} p_i = 1$.

**Определение:**  
Математическим ожиданием дискретной случайной величины называется сумма произведений всех её возможных значений на их вероятности:
$$E[X]=\sum_{i=1}^{\infty} x_i p_i$$

---

### 2. Непрерывный случай: случайная величина с непрерывным распределением

Пусть $X$ — непрерывная случайная величина с плотностью распределения $f(x) \ge 0$, интегрируемой по всей области определения, и $\int_{-\infty}^{\infty} f(x)\,dx = 1$. 

**Определение:**  
Математическим ожиданием непрерывной случайной величины называется несобственный интеграл от произведения функции плотности на аргумент:
$$E[X]=\int_{-\infty}^{\infty} x\,f(x)\,dx$$

---

## Основные свойства математического ожидания

### 1. Математическое ожидание константы ($c$)

$$E[c]=c$$

*Доказательство:*  
- Для дискретного случая: $E[c]=\sum c \, p_i = c\sum p_i = c$  
- Для непрерывного случая: $E[c]=\int c \, f(x)\, dx = c\int f(x)\, dx = c$

### 2. Линейность математического ожидания

Для любых случайных величин $X$ и $Y$ и любых постоянных $a, b$:

$$E[aX + bY] = aE[X] + bE[Y]$$

*Доказательство:* (дискретный случай)  
$$E[aX + bY] = \sum (ax_i + by_i)p_i = a\sum x_i p_i + b\sum y_i p_i = aE[X] + bE[Y].$$

Аналогично для непрерывного случая через интегралы.

### 3. Ожидание суммы

$$E[X+Y] = E[X] + E[Y]$$

Это следствие линейности из предыдущего пункта.

### 4. Ожидание разности

$$E[X - Y] = E[X] - E[Y]$$

Следствие из линейности: $E[X-Y] = E[X+(-1)\cdot Y] = E[X]+E[-1\cdot Y] = E[X]-E[Y]$.

### 5. Свойство постоянства (сдвиг):

Если $c$ — константа, то $E[X+c] = E[X] + c$

*Доказательство:*  
- Дискретно: $E[X+c] = \sum (x_i + c)p_i = \sum x_i p_i + c\sum p_i = E[X] + c$  
- Непрерывно: $E[X+c] = \int (x+c)f(x)\,dx = \int x f(x)\,dx + c\int f(x)\,dx = E[X] + c$

### 6. Ожидание произведения независимых величин

Если $X$ и $Y$ независимы, то $E[XY] = E[X]\cdot E[Y]$

*Доказательство:* (для дискретных величин)  
$$E[XY] = \sum_{i,j} x_i y_j p_{ij}, \quad p_{ij}=P(X=x_i,Y=y_j).$$  
При независимости $p_{ij}=p_i q_j$, где $p_i=P(X=x_i), q_j=P(Y=y_j)$. Тогда:
$$E[XY] = \sum_i x_i p_i \sum_j y_j q_j = E[X]E[Y].$$

Аналогично для непрерывных.

## Примеры вычисления

### Пример 1: Дискретная случайная величина

Случайная величина $X$ принимает значения $-1, 0, 1$ с вероятностями $0.2, 0.5, 0.3$ соответственно.

$$E[X] = (-1)(0.2) + (0)(0.5) + (1)(0.3) = -0.2 + 0 + 0.3 = 0.1$$

### Пример 2: Непрерывная случайная величина

Плотность равномерного распределения на отрезке $[0, 2]$: $f(x)=\frac{1}{2}$ при $0\le x\le 2$.

$$E[X] = \int_{0}^{2} x \cdot \frac{1}{2}\,dx = \frac{1}{2}\left[\frac{x^2}{2}\right]_0^{2} = \frac{1}{4}(2^2 - 0) = \frac{4}{4} = 1$$
