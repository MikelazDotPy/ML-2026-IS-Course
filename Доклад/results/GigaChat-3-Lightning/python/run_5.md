Вот реализация функции на Python, которая подсчитывает частоту слов в строке с учетом игнорирования регистра и знаков препинания:

### Решение
1. Используем регулярные выражения для извлечения только буквенных слов (игнорируя знаки препинание).
2. Приводим все слова к нижнему регистру.
3. Подсчёт количества вхождений реализуем через `collections.Counter`.

### Код

```python
import re
from collections import Counter

def word_count(text):
    # Находим все последовательности букв, игнорируя регистр и символы
    words = re.findall(r'\b[a-zA-Z]+\b', text.lower())
    # Подсчитываем количество каждого слова
    return dict(Counter(words))
```

### Краткое объяснение:
- `re.findall(r'\b[a-zA-Z]+\b', text.lower())` — извлекает из строки отдельные слова (только буквы), приводя их к нижнему регистру.
- `Counter` подсчитывает каждое слово, а итоговый результат преобразуется в обычный словарь (`dict`).

### Пример вызова:

```python
text = "Привет! Привет, как дела? Дела хорошие. ПрИвет!"
result = word_count(text)
print(result)
# Вывод: {'привет': 3, 'как': 1, 'дела': 2, 'хорошие': 1}
```

**Что происходит:**  
- «Привет» встречается 3 раза (учитывая регистр не важен).  
- «Как», «дела», «хорошие» — по одному разу.  
- Знаки препинания («!», «,») полностью игнорируются.
