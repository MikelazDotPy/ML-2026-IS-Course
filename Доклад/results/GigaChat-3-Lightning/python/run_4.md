Вот решение задачи на Python:

**Код функции:**
```python
import re
from collections import Counter

def word_count(text):
    # Приводим строку к нижнему регистру и убираем знаки препинания (оставляем только буквы и пробелы)
    cleaned = re.sub(r'[^a-zа-я ]', '', text.lower())
    
    # Разбиваем строку на слова по пробелам
    words = cleaned.split()
    
    # Подсчитываем количество каждого слова с помощью Counter
    return dict(Counter(words))
```

**Краткое объяснение решения:**
- Используем `re.sub()` для удаления знаков препинания, оставляя только буквы русского/английского алфавита и пробелы.
- С помощью `.lower()` делаем все символы в нижнем регистре (регистр не учитывается).
- Далее разбиваем текст через `.split()`.
- Для подсчёта используем встроенный модуль `collections.Counter`, который возвращает словарь частот слов.

**Пример вызова:**
```python
text = "Привет! Как дела? Привет, привет!"
result = word_count(text)
print(result)  # {'привет': 3, 'как': 1, 'дела': 1}
```

**Что делает результат:**
- Знак препинания (`!`, `?`, `,`) удаляется.
- Регистр игнорируется — «Привет» и «привет» считаются одним словом.
