Вот функция на Python, которая решает поставленную задачу:

**Код:**
```python
import re
from collections import Counter

def word_count(text):
    """
    Возвращает словарь с количеством вхождений каждого слова.
    Регистр не учитывается, знаки препинания игнорируются.
    """
    # Приводим текст к нижнему регистру и убираем знаки препинания (кроме букв и пробелов)
    words = re.findall(r'\b\w+\b', text.lower())
    return dict(Counter(words))
```

### Краткое объяснение решения:
1. **Регулярное выражение (`re`)**:  
   - `\w+` — находит все последовательности из букв, цифр или символов подчеркивания (то есть «слова»).
   - `.lower()` — переводит всё в нижний регистр для учета регистра безразлично.
2. **`Counter` из модуля `collections`**: автоматически подсчитывает количество каждого элемента в списке.
3. **Результат** — преобразуем кортеж-словарь в обычный `dict`.

**Пример вызова:**
```python
text = "Привет! Привет, как дела? Дела, дела... Да-да!"
result = word_count(text)
print(result)
# Вывод: {'привет': 2, 'как': 1, 'дела': 3, 'да': 2}
```

*Замечание:* Если требуется учесть только буквы русского алфавита (без цифр/подчеркиваний), можно заменить `\w` на `[а-яё]+`, но стандартная реализация подходит под большинство задач.*
