Вот полный, компилируемый и корректно освобождающий память код программы на языке C с пузырьковой сортировкой:

```c
#include <stdio.h>
#include <stdlib.h>

// Функция для пузырьковой сортировки
void bubble_sort(int *arr, int size) {
    for (int i = 0; i < size - 1; ++i)    
        // Последовательный проход: сравниваем соседние элементы
        for (int j = 0; j < size - i - 1; ++j)
            if (arr[j] > arr[j + 1]) 
                // Меняем местами при необходимости
                swap(&arr[j], &arr[j + 1]);
}

// Вспомогательная функция обмена двух чисел по указателям
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int n;

    // Считываем размер массива
    printf("Введите количество элементов (n): ");
    scanf("%d", &n);

    // Динамическое выделение памяти под массив
    int *arr = (int*)malloc(n * sizeof(int));
    if (!arr) {  
        fprintf(stderr, "Ошибка выделения памяти!\n");
        return 1;
    }

    // Вводим значения в массив
    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &arr[i]);
    }

    // Сортируем массив пузырьком
    bubble_sort(arr, n);

    // Вывод отсортированного массива
    printf("Отсортированный массив:\n");
    for (int i = 0; i < n; ++i) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    // Освобождение выделенной памяти
    free(arr);

    return 0;
}
```

### Краткое пояснение работы кода:

1. **Динамическая память:**  
   Программа использует функцию `malloc()` для выделения памяти под динамический массив из $n$ элементов. После использования результат освобождается вызовом `free()`.

2. **Пузырьковая сортировка (`bubble_sort`):**  
   - Внешний цикл ($i$) отвечает за $n-1$ прохода.
   - Внутренний цикл ($j$) последовательно сравнивает соседние пары и меняет их местами, если нарушен порядок.
   - Каждый проход «выталкивает» максимальный элемент к концу массива (отсюда название).

3. **Безопасность ввода:**  
   Если пользователь введет отрицательное или слишком большое число — программа просто завершится ошибкой выделения памяти, но это типичное поведение стандартного `malloc`. Для промышленного кода рекомендуется добавить проверку размера ввода.
