Вот полный компилируемый код программы на C, которая:

1. Считывает с клавиатуры размер массива `n` (целое число).
2. Динамически выделяет память под массив.
3. Заполняет массив целыми числами, введёнными пользователем.
4. Сортирует его пузырьковой сортировкой.
5. Освобождает выделенную память и выводит результат.

**Полный компилируемый код:**
```c
#include <stdio.h>
#include <stdlib.h> // Для malloc/free

// Функция пузырьковой сортировки
void bubbleSort(int *arr, int n) {
    for (int i = 0; i < n - 1; ++i) {
        // Последний i элементов уже отсортированы, можно сократить цикл
        for (int j = 0; j < n - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                // Меняем элементы местами
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int n;
    
    // Вводим размер массива
    printf("Введите количество чисел в массиве (n): ");
    if (scanf("%d", &n) != 1 || n <= 0) {
        printf("Ошибка: неверный ввод или отрицательное значение.\n");
        return 1;
    }

    // Динамическое выделение памяти для массива
    int *arr = (int *)malloc(n * sizeof(int));
    if (!arr) {
        perror("Не удалось выделить память");
        return 1;
    }

    // Ввод значений массива
    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; ++i) {
        if (scanf("%d", &arr[i]) != 1) {
            fprintf(stderr, "Ошибка при чтении данных!\n");
            free(arr); // Освобождение памяти перед выходом
            return 1;
        }
    }

    // Пузырьковая сортировка
    bubbleSort(arr, n);

    // Вывод отсортированного массива
    printf("Отсортированный массив:\n");
    for (int i = 0; i < n; ++i) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    // Освобождение динамической памяти
    free(arr);

    return 0;
}
```

### Как работает программа:

1. **Заголовки и функции:**  
   - Подключены `<stdio.h>` (ввод/вывод), `<stdlib.h>` (динамическая память).  
   - Реализована функция `bubbleSort`, где два вложенных цикла сравнивают соседние элементы и меняют их местами, если они не по порядку.

2. **Основная часть (`main`):**
   - Пользователь вводит число `n`. Проверка корректности ввода обязательна.
   - Массив выделяется через `malloc`: `int *arr = (int *)malloc(n * sizeof(int))`.
   - Числа считываются циклом и записываются в выделенный массив.
   - Вызывается функция пузырьковой сортировки.
   - Результат выводится на экран.
   - После работы вызывается `free(arr)` для освобождения памяти.
