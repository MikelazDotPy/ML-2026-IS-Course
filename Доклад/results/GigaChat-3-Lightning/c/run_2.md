Вот полный компилируемый пример программы на C, реализующий пузырьковую сортировку динамически выделенного массива с последующим освобождением памяти:

```c
#include <stdio.h>
#include <stdlib.h> // Для malloc и free

// Функция пузырьковой сортировки (bubble sort)
void bubble_sort(int* arr, int n) {
    for (int i = 0; i < n - 1; ++i) { // Проход по всем элементам (кроме последнего уже отсортированного)
        for (int j = 0; j < n - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                // Меняем местами соседние элементы при необходимости
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int n;

    // Ввод размера массива
    printf("Введите размер массива: ");
    scanf("%d", &n);

    // Проверка корректности ввода
    if (n <= 0) {
        printf("Ошибка: размер должен быть положительным числом.\n");
        return 1;
    }

    // Динамическое выделение памяти под массив
    int* arr = (int*)malloc(n * sizeof(int));
    if (!arr) {
        perror("Ошибка выделения памяти");
        return 1;
    }

    // Ввод элементов массива
    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &arr[i]);
    }

    // Сортировка пузырьком
    bubble_sort(arr, n);

    // Вывод отсортированного массива
    printf("Отсортированный массив: ");
    for (int i = 0; i < n; ++i) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    // Освобождение выделенной памяти
    free(arr);

    return 0;
}
```

### Как работает программа:
1. **Заголовки:** Подключены `stdio.h` (ввод/вывод) и `stdlib.h` (управление памятью).
2. **Функция `bubble_sort`:**
   - Внешний цикл (`for`) уменьшает диапазон проверки после каждого прохода.
   - Внутренний цикл сравнивает соседние пары и меняет их местами, если они не в порядке.
3. **Основная функция `main`:**
   - Запрашивает у пользователя размер массива и проверяет его валидность.
   - Выделяет память под массив с помощью `malloc`.
   - Вводит числа с клавиатуры.
   - Вызывает функцию сортировки.
   - Выводит результат.
   - После использования вызывает `free()` для освобождения памяти (предотвращение утечек).

**Компилирование:**  
Сохраните код в файл `bubble.c`, затем выполните команду:
```bash
gcc -o bubble bubble.c
```
И запускайте: `./bubble`

Обратите внимание: пузырьковая сортировка имеет сложность $O(n^2)$ и неэффективна для больших массивов, но отлично подходит для учебных целей.
