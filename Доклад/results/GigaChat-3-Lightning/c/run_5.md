Вот полный компилируемый и рабочий пример программы на языке C, который считывает массив чисел с клавиатуры, сортирует его пузырьковой сортировкой (Bubble Sort), выводит результат и корректно освобождает выделенную память:

### Код программы:
```c
#include <stdio.h>
#include <stdlib.h> // Для malloc/free

// Функция пузырьковой сортировки
void bubble_sort(int *arr, int n) {
    for (int i = 0; i < n - 1; ++i) {
        // Проверка соседних элементов на взаимное расположение
        for (int j = 0; j < n - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                // Меняем местами
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int n;

    // Ввод размера массива
    printf("Введите количество элементов массива: ");
    scanf("%d", &n);

    // Динамическое выделение памяти под массив
    int *arr = (int *)malloc(n * sizeof(int));
    if (!arr) {
        fprintf(stderr, "Ошибка выделения памяти!\n");
        return 1;
    }

    // Ввод элементов массива
    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &arr[i]);
    }

    // Выполнение пузырьковой сортировки
    bubble_sort(arr, n);

    // Вывод отсортированного массива
    printf("Отсортированный массив:\n");
    for (int i = 0; i < n; ++i) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    // Освобождение динамической памяти
    free(arr);

    return 0;
}
```

### Краткое пояснение работы программы:

1. **Подключение библиотек:**  
   Используются `<stdio.h>` для ввода-вывода (`printf`, `scanf`) и `<stdlib.h>` для управления памятью (`malloc`, `free`).

2. **Динамическая память:**  
   Размер массива определяется пользователем (`n`). Память выделяется функцией `malloc`:  
   ```c
   int *arr = (int *)malloc(n * sizeof(int)); 
   ```
   После использования обязательно освобождается вызовом `free(arr)` во избежание утечек.

3. **Пузырьковая сортировка (`bubble_sort`):**  
   Сравнивает соседние элементы массива и меняет их местами, если они стоят не по порядку. Повторяется до полного упорядочивания.

4. **Логика работы:**  
   - Сначала пользователь вводит размер массива.
   - Затем вводятся сами элементы.
   - Массив сортируется.
   - Результат выводится на экран.
   - Память очищается.

### Как собрать программу?
Сохраните код в файл `bubble_sort.c`. Затем выполните компиляцию командой:
```bash

```
И запускайте:
```bash
./bubble_sort
```
