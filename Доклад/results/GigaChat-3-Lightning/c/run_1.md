Вот полный компилируемый и рабочий пример программы на языке C, реализующий сортировку пузырьком с динамическим выделением памяти:

```c
#include <stdio.h>
#include <stdlib.h>

// Функция для вывода массива (для отладки)
void print_array(int* arr, int size) {
    for (int i = 0; i < size; ++i) {
        printf("%d ", arr[i]);
    }
    printf("\n");
}

// Пузырьковая сортировка
void bubble_sort(int* arr, int n) {
    int temp;
    for (int i = 0; i < n - 1; ++i) { // Проход по массиву
        for (int j = 0; j < n - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                // Меняем элементы местами
                temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

int main() {
    int n;

    // Ввод размера массива
    printf("Введите размер массива: ");
    scanf("%d", &n);

    // Динамическое выделение памяти под массив
    int* arr = (int*)malloc(n * sizeof(int));
    if (!arr) {
        fprintf(stderr, "Ошибка выделения памяти!\n");
        return 1;
    }

    // Ввод элементов массива
    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &arr[i]);
    }

    // Сортируем массив
    bubble_sort(arr, n);

    // Вывод отсортированного массива
    printf("Отсортированный массив:\n");
    print_array(arr, n);

    // Освобождение памяти
    free(arr);

    return 0;
}
```

### Как это работает:
1. **Динамическая память:**  
   Для хранения массива используется `malloc`, который выделяет нужное количество байт в куче. Размер массива определяется пользователем (`n`). После использования память освобождается через `free`.
2. **Пузырьковая сортировка (`bubble_sort`):**  
   - Внешний цикл проходит `n-1` раз.
   - Внутренний цикл сравнивает соседние элементы и меняет их местами, если они не в порядке.
   - С каждым проходом максимальный элемент «всплывает» на последнее место, поэтому длина внутреннего цикла уменьшается (`n-i-1`).
3. **Функция `print_array`:**  
   Помогает вывести содержимое массива для проверки результата.
4. **Обработка ошибок:**  
   Проверяется успешность выделения памяти (`if (!arr)`), чтобы избежать утечек или крашей при нехватке ресурсов.
