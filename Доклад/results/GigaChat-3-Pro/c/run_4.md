Вот полный код программы на языке C, которая считывает массив целых чисел с клавиатуры, сортирует его пузырьковой сортировкой и выводит результат. Память выделяется динамически и освобождается после использования.

```c
#include <stdio.h>
#include <stdlib.h>

// Функция для обмена двух элементов массива
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// Реализация пузырьковой сортировки
void bubbleSort(int *arr, int n) {
    for (int i = 0; i < n - 1; ++i) {
        // Флаг для оптимизации: если за проход не было обменов — массив уже отсортирован
        int swapped = 0;
        for (int j = 0; j < n - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                swap(&arr[j], &arr[j + 1]);
                swapped = 1;
            }
        }
        if (!swapped)
            break;
    }
}

int main() {
    int n;

    // Ввод размера массива
    printf("Введите количество элементов в массиве: ");
    scanf("%d", &n);

    // Проверка корректности ввода
    if (n <= 0) {
        printf("Ошибка: размер массива должен быть положительным.\n");
        return 1;
    }

    // Динамическое выделение памяти под массив
    int *arr = (int *)malloc(n * sizeof(int));
    if (arr == NULL) {
        printf("Ошибка выделения памяти!\n");
        return 1;
    }

    // Ввод элементов массива
    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &arr[i]);
    }

    // Сортировка массива пузырьком
    bubbleSort(arr, n);

    // Вывод отсортированного массива
    printf("Отсортированный массив:\n");
    for (int i = 0; i < n; ++i) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    // Освобождение выделенной памяти
    free(arr);

    return 0;
}
```

### Как работает программа:

1. **Динамическая память:**  
   Массив из $n$ элементов создаётся с помощью `malloc`. После завершения работы память освобождается через `free`, чтобы избежать утечек памяти.

2. **Пузырьковая сортировка:**  
   Алгоритм сравнивает соседние элементы и меняет их местами, если они стоят в неправильном порядке. Этот процесс повторяется до тех пор, пока весь массив не будет отсортирован.

3. **Оптимизация:**  
   Используется флаг `swapped`: если во время прохода по массиву ни одна пара элементов не была поменяна местами, значит, массив уже отсортирован, и цикл завершается досрочно.

4. **Обработка ошибок:**  
   Программа проверяет, что введённое число $n$ положительное, а также убеждается, что память успешно выделена.

Программа полностью соответствует требованиям задачи и готова к компиляции и запуску.
