Вот полный компилируемый код программы на языке C, которая считывает массив из $n$ целых чисел с клавиатуры, сортирует его пузырьковой сортировкой и выводит результат. Память выделяется динамически, а после использования освобождается.

```c
#include <stdio.h>
#include <stdlib.h>

// Функция для обмена двух элементов массива
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// Реализация пузырьковой сортировки
void bubbleSort(int *arr, int n) {
    for (int i = 0; i < n - 1; ++i) {
        // Флаг оптимизирующий: если в ходе прохода не было обменов,
        // значит массив уже отсортирован и можно завершить работу
        int swapped = 0;
        
        for (int j = 0; j < n - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                swap(&arr[j], &arr[j + 1]);
                swapped = 1;
            }
        }
        if (!swapped)
            break;
    }
}

int main() {
    int n;
    
    printf("Введите количество элементов массива: ");
    scanf("%d", &n);
    
    // Динамическое выделение памяти под массив
    int *arr = (int *)malloc(n * sizeof(int));
    
    if (arr == NULL) {
        fprintf(stderr, "Ошибка выделения памяти\n");
        return 1;
    }
    
    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; ++i) {
        scanf("%d", &arr[i]);
    }
    
    // Сортировка массива пузырьком
    bubbleSort(arr, n);
    
    // Вывод отсортированного массива
    printf("Отсортированный массив:\n");
    for (int i = 0; i < n; ++i) {
        printf("%d ", arr[i]);
    }
    printf("\n");
    
    // Освобождение выделенной памяти
    free(arr);
    
    return 0;
}
```

### Краткое пояснение работы программы:

1. **Чтение размера массива**: 
   Сначала программа запрашивает у пользователя число `n`, которое определяет размер массива.

2. **Динамическое выделение памяти**:
   Используется функция `malloc()` для выделения памяти под массив из `n` элементов типа `int`. Если память не удается выделить, выводится сообщение об ошибке.

3. **Заполнение массива**:
   Программа предлагает пользователю ввести значения массива по одному.

4. **Сортировка пузырьком** (`bubbleSort`):
   Алгоритм проходит несколько раз по массиву, сравнивая соседние элементы и меняя их местами при необходимости. После каждого полного прохода самый большой элемент оказывается в конце массива ("всплывает" как пузырек), отсюда и название алгоритма.
   
5. **Оптимизация**: 
   Если за один проход не произошло ни одного обмена, это означает, что массив уже отсортирован, и алгоритм завершает работу раньше.

6. **Освобождение памяти**:
   После завершения работы с массивом используется `free()` для освобождения выделенной ранее памяти.

7. **Вывод результата**:
   Отсортированный массив выводится на экран.

Программа полностью соответствует требованиям задачи: использует динамическую память, корректно её освобождает и реализует классическую пузырьковую сортировку.
