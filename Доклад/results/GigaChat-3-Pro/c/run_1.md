Вот полный компилируемый код на C, который считывает массив из $ n $ целых чисел с клавиатуры, сортирует его пузырьковой сортировкой и выводит результат:

```c
#include <stdio.h>
#include <stdlib.h>

// Функция для обмена двух элементов массива
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

// Пузырьковая сортировка
void bubbleSort(int *arr, int size) {
    for (int i = 0; i < size - 1; ++i) {
        // Флаг для оптимизации: если за один проход не было обменов,
        // значит массив уже отсортирован
        int swapped = 0;
        for (int j = 0; j < size - i - 1; ++j) {
            if (arr[j] > arr[j + 1]) {
                swap(&arr[j], &arr[j + 1]);
                swapped = 1;
            }
        }
        if (!swapped) break;  // Массив отсортирован досрочно
    }
}

int main() {
    int n;

    // Ввод размера массива
    printf("Введите количество элементов: ");
    scanf("%d", &n);

    if (n <= 0) {
        printf("Ошибка: размер массива должен быть положительным.\n");
        return 1;
    }

    // Динамическое выделение памяти под массив
    int *array = (int *)malloc(n * sizeof(int));
    if (array == NULL) {
        printf("Ошибка выделения памяти!\n");
        return 1;
    }

    // Чтение элементов массива
    printf("Введите %d целых чисел:\n", n);
    for (int i = 0; i < n; ++i) {
        printf("Элемент [%d]: ", i);
        scanf("%d", &array[i]);
    }

    // Сортировка массива
    bubbleSort(array, n);

    // Вывод отсортированного массива
    printf("\nОтсортированный массив:\n");
    for (int i = 0; i < n; ++i) {
        printf("%d ", array[i]);
    }
    printf("\n");

    // Освобождение выделенной памяти
    free(array);

    return 0;
}
```

### Как это работает

1. **Динамическая память**  
   Программа запрашивает у пользователя число $ n $, затем выделяет динамически массив размером $ n $ с помощью `malloc`. После завершения работы память освобождается через `free`.

2. **Чтение данных**  
   Пользователь вводит поочередно $ n $ целых чисел.

3. **Пузырьковая сортировка**  
   Алгоритм проходит по массиву несколько раз. На каждом шаге сравниваются соседние элементы и меняются местами, если они стоят в неправильном порядке. Процесс повторяется до тех пор, пока весь массив не будет отсортирован. Для оптимизации добавлен флаг `swapped`, позволяющий выйти раньше, если массив уже отсортирован.

4. **Вывод результата**  
   Отсортированный массив выводится на экран.

5. **Очистка ресурсов**  
   Перед завершением программы выделенная ранее память освобождается функцией `free`.

Программа корректно обрабатывает ошибки при выделении памяти и некорректный ввод размера массива.
