## Решение

Чтобы корректно подсчитать частоту слов в строке, нужно:

1. Нормализовать регистр (привести все слова к нижнему регистру).
2. Удалить знаки препинания и другие символы, не относящиеся к словам.
3. Разбить строку на отдельные слова по пробелам.
4. Подсчитать количество появлений каждого уникального слова с помощью словаря.

Для этого можно использовать регулярные выражения (`re`), чтобы убрать лишние символы перед разбиением строки.

---

## Код функции

```python
import re
from collections import Counter

def word_count(text: str) -> dict:
    # Убираем всё кроме букв и цифр, приводим к нижнему регистру
    cleaned_text = re.sub(r'[^a-zA-Z0-9\s]', '', text.lower())
    
    # Делим текст на слова
    words = cleaned_text.split()
    
    # Считаем частоту появления слов
    return dict(Counter(words))
```

---

## Пояснение работы кода

- `re.sub(r'[^a-zA-Z0-9\s]', '', text.lower())` — убирает из текста все символы, кроме латинских букв, цифр и пробелов; переводит весь текст в нижний регистр для унификации.
- `.split()` — разбивает строку на список слов по пробелам.
- `Counter(words)` — создаёт объект счётчика частот для всех элементов списка слов.
- `dict(...)` — преобразует результат обратно в обычный словарь.

---

## Пример вызова и результата

```python
text = "Hello, world! Hello Python. World is beautiful."
result = word_count(text)
print(result)
```

### Вывод:
```python
{
  'hello': 2,
  'world': 2,
  'python': 1,
  'is': 1,
  'beautiful': 1
}
```
