## Решение задачи

Для подсчёта частоты слов в строке нужно выполнить следующие шаги:

1. **Нормализовать регистр** — привести всю строку к нижнему регистру.
2. **Удалить знаки препинания** — чтобы слова не считались с лишними символами (например, "слово," и "слово" должны считаться одинаковыми).
3. **Разбить текст на слова** по пробелам или другим разделителям.
4. **Подсчитать частоту каждого слова**, используя словарь: ключ — слово, значение — количество его повторений.
5. Вернуть полученный словарь.

## Код функции

```python
import re
from collections import defaultdict

def word_frequency(text):
    # Приводим текст к нижнему регистру
    text = text.lower()
    
    # Удаляем все символы, кроме букв и цифр
    words = re.findall(r'\b\w+\b', text)
    
    frequency = defaultdict(int)
    
    for word in words:
        frequency[word] += 1
        
    return dict(frequency)
```

### Краткое объяснение решения

- Используется регулярное выражение `\b\w+\b`, которое находит все последовательности символов, состоящие из букв и цифр, окружённые границами слов (`\b`). Это позволяет игнорировать знаки препинания.
- Словарь `defaultdict(int)` автоматически создаёт счётчик для новых ключей.
- В конце функция возвращает обычный словарь.
