## Решение задачи

Для подсчёта количества слов в строке с игнорированием регистра и знаков препинания, выполним следующие шаги:

1. **Нормализация строки**  
   Приведём всю строку к нижнему регистру (или верхнему), чтобы регистр не влиял на результат.
2. **Удаление знаков пунктуации**  
   Воспользуемся регулярными выражениями для удаления всех символов, кроме букв и пробелов (буквы — только русские или латинские).
3. **Разделение на слова**  
   Разобьём полученную строку по пробелам, отфильтровав пустые элементы.
4. **Подсчёт частоты слов**  
   Используем `collections.Counter` для удобного подсчёта повторяющихся слов.
5. **Возврат результата в виде обычного словаря**

## Код функции

```python
import re
from collections import Counter

def count_words(text):
    # Нормализуем регистр
    text = text.lower()
    
    # Удаляем знаки пунктуации, оставляя буквы и пробелы
    clean_text = re.sub(r'[^a-zа-яё ]', ' ', text)
    
    # Делим на слова, убираем возможные лишние пробелы
    words = [word for word in clean_text.split() if word]
    
    # Подсчитываем частоту каждого слова
    return dict(Counter(words))
```

### Пример вызова и результат

