Вот функция на Python, которая решает поставленную задачу:

```python
import re
from collections import defaultdict

def word_count(text):
    # Приводим текст к нижнему регистру и удаляем знаки препинания (кроме апострофов)
    cleaned_text = re.sub(r"[^\w\s']", " ", text.lower())
    
    words = cleaned_text.split()
    
    counts = defaultdict(int)
    for word in words:
        if word:  # игнорируем пустые строки после удаления знаков препинания
            counts[word] += 1
            
    return dict(counts)
```

### Как работает решение:
1. **Нормализация текста**  
   - Переводим строку в нижний регистр (`lower()`), чтобы регистр не учитывался.
   - С помощью регулярного выражения `re.sub` заменяем все символы, кроме букв, цифр, пробелов и апострофа (`\w`, `\s`, `'`), на пробел. Это позволяет удалить знаки препинания.
2. **Разбиение на слова**
   - Используем метод `split()`, который разделяет строку по пробельным символам.
3. **Подсчёт слов**
   - Применяем словарь `defaultdict(int)` для автоматического подсчёта количества каждого слова.
4. **Возврат результата**
   - Преобразуем результат в обычный словарь перед возвратом.
