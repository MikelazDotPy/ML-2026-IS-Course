## Решение задачи

Для подсчёта частоты слов в строке необходимо:

1. Привести строку к нижнему регистру, чтобы регистр не учитывался.
2. Удалить все знаки препинания (или игнорировать их при разделении на слова).
3. Разбить текст на отдельные слова.
4. Подсчитать количество каждого уникального слова и сохранить результат в словарь.
5. Для удаления пунктуации удобно использовать регулярное выражение `re.sub`, заменяя любые символы, кроме букв и цифр, пробелами или удаляя их вовсе.

## Код функции на Python

```python
import re
from collections import Counter

def count_words(text):
    # Преобразуем текст к нижнему регистру
    text = text.lower()
    
    # Заменяем знаки пунктуации пробелами для корректного разделения слов
    text = re.sub(r'[^\w\s]', ' ', text)
    
    # Делим строку на список слов по пробелам
    words = text.split()
    
    # Используем Counter из модуля collections для подсчета слов
    return dict(Counter(words))
```

### Пояснение шагов кода

- **`text.lower()`** — приводит всю строку к нижнему регистру.
- **`re.sub(r'[^\w\s]', ' ', text)`** — с помощью регулярного выражения заменяет любой символ, который не является буквой, цифрой или пробелом (`\w` и `\s`), на пробел. Это позволяет корректно отделять слова друг от друга даже если они были написаны слитно через запятую, точку и т.д.
- **`split()`** — разбивает строку на слова по пробельным символам.
- **`Counter(words)`** — считает частоту появления каждого элемента в списке слов и возвращает объект класса `Counter`. Метод `dict(...)` преобразует его в обычный словарь.

## Пример вызова функции и результат

```python
sample_text = "Привет! Как дела? Привет-привет, мир! Мир-мир."
result = count_words(sample_text)
print(result)
```

```python
{'привет': 3, 'как': 1, 'дела': 1, 'мир': 2}
```

Таким образом, функция корректно считает слова независимо от регистра и знаков препинания.
